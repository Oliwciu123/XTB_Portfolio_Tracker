# XTB Portfolio Tracker v1.3.1

- Removed chart gridlines throughout the report.
- Double-click outside a plot to restore the visible charts to their default
  ranges. In Deposits, the selected years, months and grouping stay in place.
- Enlarged the six section tabs and removed redundant captions and zoom prompts.

Download the portable ZIP for Windows or macOS and extract the entire archive.
The bundled demo works offline. Real portfolios use internet access for market
data. Windows requires Microsoft Edge WebView2.
